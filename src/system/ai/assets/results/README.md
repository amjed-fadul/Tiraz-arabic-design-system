# Local AI result examples

Original hand-authored SVG illustrations by Tiraz contributors, 2026. Fictional
menu briefs and audit text created for component demonstrations. No real
research, image generation, retrieval, people or business data is represented.
Covered by the bundled [MIT license](../LICENSE.txt).

Copy this entire `results/` directory along with `ai/`. Preserve the example's
local imports (`?url&no-inline` for text documents); Vite supplies asset URL handling via
`vite/client`. For another bundler, use its asset URL support or copy the files
to the host public directory and replace the imports with those real paths.
Keep image alt text and sample-content notices when adapting the example.
