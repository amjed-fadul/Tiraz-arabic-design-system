# Chip implementation plan

> Use superpowers:executing-plans inline, with one final independent review.

**Goal:** Reuse one accessible Chip for filters and category navigation.
**Architecture:** Native button/link union, shared CSS; host-managed state and
existing route handling. One source example also feeds the workbench generator.
**Tech stack:** React 19, TypeScript, existing tokens, Vitest/jsdom, Vite.
**Spec:** docs/superpowers/specs/2026-10-25-chip-design.md.

## Global constraints

Local only. Preserve owner output/, landing and documentation layout. Keep 5411
serving this branch. No package bump, push, merge or deployment. Native semantics,
logical CSS, tokens, hover gating and bilingual copy.

- Controlled selection, refs and native form defaults remain correct.
- Category links retain modifier-click/new-tab behavior and current-page state.
- Inspector options produce working examples and compilable copied code.
- Chip is included in public metadata, npm/source and selective installation.
